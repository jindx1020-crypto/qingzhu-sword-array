# 1.1 修复验收报告

验收日期：2026-09-30。游戏：青竹剑阵 · 虚天殿篇 1.1。原创代码许可：GPL-3.0-only。

**结论：本地技术验收通过。** 1.1 是修复版：修正 1.0 代码审查发现的存档、战斗收尾、界面输入与发布工具问题。存档格式 1、存档键 `fanren-qingzhu-v1`、records schema 1 与全部规则版本号不变，旧存档无需转换。

## 修复内容

### 存档

| 问题 | 1.1 处理 |
|---|---|
| 采用导入存档或恢复备份失败后，候选记录留在待保存槽；本局结算会叠加在它上面并以普通写入覆盖主档，绕过前态保护，旧档可能在备份轮换后丢失 | 待保存槽只接收通过存档校验的普通写入；恢复类失败只在原确认框内重试，不进入结算链。结算改为 `persist(s=>settleRunResult(s,…))`，由统一的写入基准决定 |
| 结算写入失败后，任何其他成功写入（如调音量）会清空待保存槽，结果被静默丢弃 | 函数式写入以待保存记录为基础叠加，并继承其备份选项；开启新历练在确认后以 `discardPending` 明确放弃 |
| 有未保存结果时从首页「继续历练」，旧规则 1／2 局可重复结算心得与局数 | 存在待保存记录或内存局有未存进度时，继续历练先确认；确认后丢弃待保存记录再从磁盘节点恢复 |
| 在设置页内触发恢复错误会把设置来源改成首页，关闭设置后当前战斗未存进度无确认丢失 | 已在设置页时不改写来源 |
| 定种种子含制表符等控制字符时，节点存档能保存，胜局成绩却永远写不进去 | 输入与开局去除控制字符；成绩条目记录可打印种子，旧局同样可以结算 |
| 导入 `history[].mode` 为 `__proto__` 的存档后，打开个人最佳整页白屏且无法导出 | 显示改用自有属性查找；游戏外层加错误边界，渲染异常时显示只读导出页（原始记录汇总、本次待保存记录、重新载入），不写存储 |
| 未通过校验的记录进入待保存槽后，重试永远失败 | 这类记录不进入待保存槽，提示中只提供导出 |

### 战斗

- 合符连线（K10）在节点完成后继续对旧敌人数组结算：可多算击杀、把分裂体带进整备存档；同一帧后续的敌方危险区还能在整备状态击倒韩立。1.1 在连线循环和危险区循环中于阶段变化后立即停止，秘境引擎的 `hitPlayer` 在非战斗阶段不再扣血。规则 1／2 旧引擎行为不变。
- 种子随机数生成器的内部累加值改为 32 位回绕：约 493 万次抽取之前输出逐位相同，之后连续游玩与读档结果不再分叉。存档中保存的状态值不变。

以上属于错误修复，对在途局同样生效；只影响连线收尾那一帧的边缘结果，不改变其他数值、刷怪或随机抽样。

### 界面与输入

- 图片载入失败页的「打开 PNG 兼容版」按实际入口名称跳转：免安装包 `开始游戏.html → 兼容版/开始游戏_PNG.html`，GitHub 单文件 `qingzhu-<版本>.html → qingzhu-<版本>-png.html`，本地构建保持原名。入口名称集中在 `game/gameplay/delivery-names.js`，打包脚本共用。
- 结算页「个人最佳与最近尝试」可按 Esc 关闭。
- macOS 按住 Command 时松开方向键不再卡住移动；输入法组字中的按键（含 Esc）不再触发游戏快捷键；失焦时清除被拦截的空格／回车记录。
- 确认框被另一窗口的写入原地替换时，确认键短暂禁用并把焦点移回取消，避免把旧问题的点击用于新问题。
- 观察包导入增加 8 MiB 上限；设置页每次渲染只读取一次隔离原文数量；声音总线仅在音量变化时重排。

### 构建与发布

- 构建依赖安全更新：`@cloudflare/vite-plugin` 1.62.2、`wrangler` 4.144.0、`@cloudflare/workers-types` 5.20260926.1，间接依赖 undici、brace-expansion、fast-uri、ip-address 升级，`npm audit` 0 项。离线成品实际内嵌的依赖版本不变。
- 新增 `npm run docs:deps`，从锁文件与已安装依赖重新生成依赖清单和许可原文；对 1.0 锁文件运行时与原清单逐字节一致。删除一份未被引用的许可原文。
- 离线 HTML 不再内嵌 Vite modulepreload 兼容脚本（其中唯一的 `fetch`）；Rolldown 写入成品的运行时辅助代码补入第三方声明与内嵌许可。许可原文按文件名排序拼接；HTML 插入改用回调，避免 `$` 替换序列。
- 源码包去除夹具中的本机临时路径；发布检查的隐私扫描覆盖全部非二进制文件及编码后的工具目录、`/private/tmp`、`/var/folders` 和 Windows 用户目录；公开白名单跳过 `.env*`、`*.pem`、`*.key`。
- `.gitattributes` 改为全部文本 LF，Windows 检出时 LICENSE 等嵌入文本不再因换行不同而改变成品哈希。

### 1.1 新增回归

- 合符连线在携物目标被击杀后不再多算击杀或把敌人带进整备；同帧爆裂区不能在整备中结束历练。

- 种子含制表符与换行的定种胜局可写入成绩。

- 采用恢复失败不改动四类存储，随后普通写入仍以原主档为基础。
- 待保存链、继续历练确认、设置来源、键盘与确认框边界及兼容版路径的源码标记。
