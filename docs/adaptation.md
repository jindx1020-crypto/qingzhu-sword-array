# 原著依据与改编边界 · 1.1

以忘语小说《凡人修仙传》为背景。游戏是非官方同人，角色对白、节点、时限、数值与路线是改编，不宣称官方授权或逐句复原原文。

## 篇章边界

主篇为乱星海炼剑后至虚天殿。第六章“虚天夺鼎”接续出鼎冰焰退避与玄骨终局。未混入小极宫人物，不提前开放大庚剑阵、风雷翅、紫罗极火或元婴境界提升。

青竹蜂云剑开篇已经炼成；局内等级决定投入的真实剑数，最多72把，不代表重新取得法宝。取得剧情器物、行囊持有和战场可用状态分开，虚天鼎入手不等于立即完整炼化。
