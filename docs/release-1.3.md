## 版本与兼容边界

- 显示版本由 `game/gameplay/version.js` 的 `GAME_VERSION` 从 1.2 改为 1.3；篇名仍为「虚天殿篇」。包与锁文件的项目版本改为 1.3.0，依赖条目不变。`package.json` 另增加 `pretest: node scripts/embed-assets.mjs`，使干净源码在测试前生成既有资源模块；除此之外包配置不变，锁文件仅项目版本改变。
- 与最后已完成的 1.2 第六批源码包比较，109 个游戏模块中 108 个逐字节相同，唯一改变是 `version.js` 的显示版本字面量。引擎、规则表、随机数、结算、存档校验、输入与成绩分组模块保持原字节。
- 存档格式 1、键 `fanren-qingzhu-v1`、records schema 1、原十项 `RULE_KEYS` 不变；旧档不转换，不清除或补造成绩。
- 新局规则仍为秘境 3、平衡 4、修持 3、内容 3、成长 5、遭遇 8、经济 4、叙事 3、集火 3、输入 2、成绩计时 1、章末分段 1；无尽挑战 2，其他模式挑战 0。旧局按各系统原标记恢复。
- 既有 `recordDetails` 会给新生成的成绩写入显示版本 1.3；旧成绩不改写。成绩分组仍读取原规则字段，不因显示版本另分组。

独立源码审核原文位于本地 `local-archive/releases/2026-10-12-v1.3/version-only-audit.json`；公开摘要见验收 JSON 的 `versionOnlyAudit`。这项审核只证明源码版本边界，不替代新 HTML 的构建与实际输入验收。
