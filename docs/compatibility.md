# 青竹剑阵项目约定

适用于本目录及所有子目录。以下维护要求来自用户的明确指示，后续工作必须遵守。

## 玩法、说明与更新日志同步

- 任何新增、调整或删除的玩法内容，都必须在同一次工作中同步更新根目录的 `青竹剑阵_游玩说明.md`，不能只改游戏后留待下次补文档。
- 同步范围包括：操作和界面提示、武器与召唤物、技能和资源、成长数值、流派与装备、敌人和关卡目标、模式、解锁条件、存档与玩家操作流程。
- 说明应描述当前实际实现的规则；核对名称、数字、触发条件、操作入口和限制，删除或修正失效说明。尤其不要混淆强化种类数与召唤物数量、灵力与雷源、取得器物与可使用状态。
- 每次更新必须同步记录到 `青竹剑阵_更新日志.md`，面向玩家说明改了什么、玩法或体验有什么变化，以及对应说明是否已更新。不要把计划或未完成内容写成已经实现。
- 同一版本内继续维护时，在该版本下追加实际修订；新版本按用户指定的版本号建立新条目，版本倒序排列。不要自行把当前版本宣布为正式版。

## 当前版本与交付

- 当前游戏显示版本为 **0.2beta**；统一来源是 `game/gameplay/version.js` 的 `GAME_VERSION`。
- 当前作品篇名为 **虚天殿篇**，统一来源为同文件的 `GAME_ARC`；网页标题使用 `GAME_TITLE`。篇名调整不改写剧情中的地理区域名称。
- 游戏界面、HTML 标题、游玩说明、更新日志、README 及当前交付文档的游戏版本标记须一致。方案文件本身的修订号与游戏版本号分开，不要全局替换依赖库版本。
- 游戏版本与存档格式版本分开管理。现有存档格式为数字 `1`，本地存档键为 `fanren-qingzhu-v1`；仅调整游戏版本号时不得修改它们或清空玩家进度。
- 修改可执行游戏内容或版本展示后，重新生成根目录的 `凡人修仙传_青竹剑阵.html`；源码与文档更新后同步 `青竹剑阵_源码.zip` 内的对应文件，包括本约定和更新日志。
- 保持交付文件可离线游玩。按改动范围验证实际行为；涉及玩法时核对说明及日志后再报告完成。
