# 游戏视频介绍页 · 1.1

本文件夹保存《青竹剑阵·虚天殿篇》视频口播介绍的源文件。介绍页是独立展示材料，不会启动游戏、读取游戏存档或向外发送数据。

## 使用

在 `release/video/` 用浏览器打开「青竹剑阵_视频介绍.html」。图片、样式和脚本全部内嵌，可以把这个 HTML 单独带到另一台电脑，离线打开。

默认 16:9 横屏，共八段，配套口播稿约 566 字，参考时长 2 分 14 秒。时长只作录制参考，可按自己的语速手动翻页。

1. 打开介绍页，先看一遍每段画面及口播稿。
2. 点击“独立提词窗口”，将提词窗口放在另一块屏幕；两边翻页会同步。
3. 主窗口按 F 全屏，按 H 进入纯画面；录屏软件只采集主窗口。
4. 用左右方向键翻页，也可按 P 自动演示。H 返回控制栏。
5. 点击“导出口播稿”保存文本；也可直接使用同目录的 [口播稿](口播稿.md)。

| 按键 | 作用 |
|---|---|
| ←／→ | 上一段／下一段 |
| 空格 | 下一段（在普通按钮上保留按钮的键盘操作） |
| F | 全屏切换 |
| H | 纯画面／返回控制栏 |
| N | 独立提词窗口 |
| P | 自动演示／暂停 |
| 1—8 | 跳到对应段落 |
| Home／End | 开场／结尾 |
| Esc | 关闭浮层或退出纯画面 |

纯画面会隐藏工具、按钮和本页稿件；字幕可在录制前关闭。页面提供演示和提词，不自动录制麦克风或生成视频文件。独立提词需要浏览器允许弹窗；如果被拦截，可使用页内口播稿或导出文本。

## 内容与素材

- 八段：开场、核心玩法、六种起手、构筑成长、六章历练、机制关卡、下一次历练、开始游玩。
- 版本和章节名称读取当前游戏源码。核心事实按 1.1 说明核对，源码与下载地址以根 README 的 GitHub 链接为准。
- 背景使用游戏现有菜单与战场图集；战斗和悟道截图来自真实游戏界面。
- 72 剑画面来自试剑台，手动布置训练敌群用于展示真实渲染，不作为自然通关或胜率证据；图上已标“试剑台 · 72 剑演示画面”。
- 封面的旋转剑阵及各段图标是介绍页的装饰图形，不是新增游戏机制。游戏美术和原著 IP 权利沿用项目 [素材说明](../assets.md)。

## 修改与重建

`content.json` 保存每段口播、字幕、时长和流派文字；`intro.template.html` 保存版式与交互；`assets/` 保存演示截图。

在 game 目录执行：

```sh
npm run build:intro
npm run test:intro
```

构建生成 `release/video/青竹剑阵_视频介绍.html`、同文件夹的口播稿副本与录制说明，并更新本目录「口播稿.md」。检查脚本在隔离、断网浏览器中验证翻页、字幕、全屏、提词双向同步、口播稿导出、自动演示、八页画面及小窗口控制栏。输出保存在 game/qa/introduction，不进入发布源码包。
